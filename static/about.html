About FlySmart

Smart Flight Search. Smarter Price Insights. FlySmart combines domestic route fare information with machine learning to help users understand flight prices.

Our Project

FlySmart is an academic flight price insight and classification system. It allows users to explore domestic routes across India and view historical fare information such as median fares, recent lows and fare ranges.

The project also uses a machine-learning model to classify flight prices into Low, Medium and High categories for supported flight details.

✈

Route Fare Insights

Explore historical fare observations for supported domestic routes and understand typical fare patterns.

🤖

Machine Learning

A trained classification model analyses supported flight features and predicts a Low, Medium or High price category.

📊

Data-Driven Insights

Historical fare statistics help users compare route-level fare patterns before making travel decisions.

💡

Smart Recommendations

FlySmart provides simple recommendations based on the flight details entered by users.

Technology Stack

  • Python for application development
  • Pandas and NumPy for data processing
  • Scikit-learn for machine learning
  • MLflow for experiment tracking
  • FastAPI for backend API development
  • HTML, CSS and JavaScript for the frontend
  • Pytest for application testing
Project Note: FlySmart provides historical route-level fare insights, not live flight availability or confirmed ticket prices. Its ML classification is limited to the feature categories supported by its training dataset.
